# Зерно — интернет-магазин кофе свежей обжарки

Учебный проект по дисциплине «Фронтенд и бэкенд разработка» (3 семестр, 2026/2027 уч. год).

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина кофе свежей обжарки «Зерно»:
каталог моносортов, эспрессо-смесей и аксессуаров, карточка товара с характеристиками,
оформление заявки, доставка и оплата, контакты с формой обратной связи.

Проект выполнен без CSS-фреймворков. JavaScript (`js/main.js`) используется только
для открытия/закрытия модального окна `<dialog>` и базовой обработки отправки форм.

## Как посмотреть проект

1. Открыть ссылку GitHub Pages выше.
2. Или локально: клонировать репозиторий и открыть `index.html` в браузере:

   ```bash
   git clone https://github.com/kikimor0607/kr1-html-css-shop.git
   cd kr1-html-css-shop
   open index.html
   ```

3. Или запустить локальный сервер: `python3 -m http.server 8000` и открыть http://localhost:8000.

## Используемые технологии

- HTML5: семантические теги `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `address`, `dialog`, `details/summary`;
- CSS3: переменные (`:root`), Flexbox, CSS Grid, состояния `:hover`, `:focus-visible`, `:disabled`, `:checked`;
- методология БЭМ для именования классов;
- минимальный JavaScript для `<dialog>` и форм;
- Git, GitHub, GitHub Pages.

## Как выполнены требования КР №1

| Требование | Где реализовано |
|---|---|
| Семантика | на всех страницах `header` → `nav`, один `main`, `section`, `article` (карточки, товар), `aside` (промо, фильтры, советы, итог заявки), `footer` |
| Единая навигация | одинаковое меню `site-nav` на всех страницах, активный пункт `site-nav__link--active` + `aria-current="page"` |
| Якорные ссылки | `index.html#advantages`, `#popular`, `#reviews`, `#contacts`; `catalog.html#mono/#blends/#accessories`; `delivery.html#tariffs/#faq`; `contacts.html#feedback` |
| Карточки | БЭМ-блок `product-card` в Grid-сетке `product-grid` |
| Таблица | `product.html` — характеристики; `delivery.html` — сравнение тарифов (`caption`, `thead`, `tbody`, `th`, `td`) |
| Форма | `order.html`, `contacts.html`, модальное окно: `label for`/`id`, `name`, `required`, `type="email"`, `pattern` для телефона |
| Модальное окно | `<dialog class="order-dialog">` на главной, в каталоге и на странице товара |
| CSS-переменные | блок `:root` (цвета, отступы, радиусы, тени, z-index) |
| Flex/Grid | Flex — шапка, меню, кнопки, формы; Grid — hero, каталог «фильтры + товары», сетки карточек, подвал, страница товара |
| Позиционирование | `sticky` — шапка, фильтры каталога, блок итога заявки; `relative` + `absolute` — карточка и бейдж, кнопка закрытия модалки; `fixed` — кнопка «Наверх»; `z-index` — шапка, бейджи, кнопка «Наверх» |

## Самостоятельные доработки

1. **Собственная визуальная концепция** — тёплая «кофейная» палитра, SVG-иллюстрации товаров, hero с иллюстрацией.
2. **Дополнительная страница `delivery.html`** — таблица сравнения тарифов доставки, способы оплаты, FAQ на `details/summary`.
3. **Расширенный каталог** — 8 товаров в 3 категориях, sticky-фильтр с ценой и наличием, панель сортировки, навигация по категориям.
4. **Варианты карточек через БЭМ-модификаторы** — `product-card--hit`, `--new`, `--discount` (старая цена), `--soldout` (серое фото, неактивная кнопка `:disabled`).
5. **Подробная карточка товара** — бейдж, рейтинг, теги вкусовых нот, выбор веса (кастомные radio `option-chip`), советы по завариванию, блок «Вам может понравиться».
6. **Блок отзывов** на главной.
7. **Улучшенный сценарий заявки** — шаги оформления, выбор помола, блок «Что будет дальше», сообщение об успешной отправке внутри формы, выбранный товар отображается в модальном окне, закрытие окна по «×», «Отмена», Esc и клику на фон.
8. **Хлебные крошки** на всех внутренних страницах (БЭМ-блок `breadcrumbs`), расширенный подвал с внутренними ссылками.
9. **Доступность** — ссылка «Перейти к содержимому», видимый `:focus-visible` у всех интерактивных элементов, `aria-current`, `aria-invalid` для ошибочных полей, `aria-describedby` для подсказки к телефону, отметка обязательных полей, `prefers-reduced-motion`.
10. **Кнопка «Наверх»** (`position: fixed`) и плавная прокрутка к якорям с учётом sticky-шапки (`scroll-padding-top`).
